How java works?
-----------------
1. JRE in-build package
- java.lang
- java.net
- java.io
- java.IO
2. JDK = JRE + JVM
3. javac -> human-readable to byte code or .class -> before compilation or conversion re-validates the entire line
of code once again.
4. class-loader loads the byte code into jvm memory when creating class instance or new object is created. When
object is created, to access the variable, methods, static variable, static methods, static class, arrays etc,
they need memory hence for the very reason, the classloader loads them in the jvm memory. After loading,
jit and interpreter reads the code line by line from the jvm memory. Interpreter, reads its, compiled it machine code
and then executes it. Redundant repeatable called is in vigilance of JIT (just in time compiler) it searches for the
redundant code put them up in the jvm cache code memory after compiling it to machine, for the next run it just
gives the redundant code for executing without needing for second or thereafter compilation. Saving time and memory.
