- What does HashMap.getOrDefault(key,defaultValue); does?
    - Returns the value mapped to the key if present,
      otherwise returns the default value you provide.

- Eg:
    Map<String, Integer> map = new HashMap<>();
    map.put("apple", 10);

    int value1 = map.getOrDefault("apple", 0);   // 10
    int value2 = map.getOrDefault("banana", 0);  // 0 (default)

- Problem:
   map.put(word, map.getOrDefault(word, 0) + 1);
